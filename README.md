- HTML structure and semantic layout
- CSS styling, responsiveness, and design basics
- JavaScript logic, loops, conditions, and functions
- DOM events and interactive UI patterns
- React fundamentals and component structure
- Git workflows and collaborative project habits

## 🚀 Getting started

```bash
git clone <repo-url>
cd "Web Development Class"
```

Then open the HTML files in a browser, or run the React apps with:

```bash
cd day16_react
npm install
npm start
```
